Objectives: 

Meet branding standards 

Colorful (visually appealing) 

Change the brown and green filter 

Change the layout of color page to match blooms and butterflies 

Add a game (clickable background) 

Keep articles, when all the boxes are clicked an arrow appears to go to clickable game 

Game = find the plant relating to the given prompt

Add information about going to game on tutorial page 

First 19

Slide 5:There are learning standards in the game and on the slide so they achieved it half way but the learning standards in the game are less detailed then they are in the slide we may want to make those match a little better.

Slide 7: There is no bog in the game. The point of the game is for there to be a bog and you click on the plant that you want to learn about and you answer questions. We have to create a bog and not just an almost learning page. You need to be able to click on a plant in the environment. There should also be more plants so we need to add more plants.

Slides 10-19: On our website there are not as many plants and when you click on a plant it is not the same. We have to make sure that when you click on the plant that you can return back to the bog and that it is more interactive. For example when you click on a plant in the current website it brings you to a passage but in the example it is more almost like a bullet point and you have to click the photo to get to them. There are also videos about some of the plants and we don't have those at all on the current website

Slides 23 - 25

Image of Butterwort plants in the background ( with three buttons, one on the bottom left hand side and the other on the bottom right hand side and one on the bottom center. The button on the bottom center states “Is this a Butterwort? Press the button below and see if you are correct!” The button on the bottom right hand side states “Yes” and the button on the bottom left hand side states “No.” Learners would click their answer, either the left button, “Yes”, or the right button, “No.” If the user clicks the button on the right hand side, “No”, the three boxes disappear and two boxes in the bottom center appear. The box higher up on the page would state, "Incorrect! Press the button to try again” the button below that one would state “TRY AGAIN!” When the user clicks “TRY AGAIN!” they will return back to the previous set up with the three buttons. If the user clicks “Yes”, the three buttons would disappear  and three new icons would appear. The first Icon would be a textbox and the bottom center on the page that writes “GREAT JOB! Let's see if you can identify more plants! Click anywhere to continue.” Slightly overlapping the top left hand corner of the bottom center button a burst bubble would appear stating “CORRECT! This is a Butterwort!” On the right hand bottom corner would be a button that says “NEXT” and when this button is clicked, it will take the user to the next slide.
